# Advanced Random Password Generator

**Автор:** Маргушева Даяна

## Описание

Продвинутый генератор случайных паролей с графическим интерфейсом на Python. Приложение позволяет:

* настраивать длину пароля (4–64 символа);
* выбирать типы символов для генерации;
* исключать неоднозначные символы (0, O, l, 1);
* просматривать историю сгенерированных паролей;
* копировать пароли в буфер обмена;
* сохранять историю между запусками.

## Функциональные возможности

* **Гибкий выбор символов:** цифры, буквы, спецсимволы.
* **Исключение неоднозначных символов** для лучшей читаемости.
* **История паролей** с датой и временем генерации.
* **Копирование в буфер обмена** одним кликом.
* **Сохранение истории** между запусками в JSON-формате.
* **Интуитивный интерфейс** с современным оформлением.
